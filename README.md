# DUCES V6 redesign

This branch contains the V6 website redesign. The `main` branch (V5) has not been modified.

## Preview
Open `index.html` in a browser or serve this folder with a static HTTP server.

## Before publishing
- Add the approved DUCES logo as `assets/duces-logo.jpg`. The header includes a text-mark fallback until the logo is added.
- The photographs currently use temporary Unsplash image URLs. Replace them with approved DUCES-owned or properly licensed photographs in `assets/` before launch.
- The enquiry form prepares an email in the visitor's email application. It does not transmit information automatically. A secure form endpoint would be needed for server-side submissions.
- Review the indicative setup package prices, tax/legal wording, privacy notice and exact service scope before launch.
- Update canonical URLs and sitemap URLs to the final V6 hosting domain after the deployment location is confirmed.
- Confirm that GitHub Pages is configured to publish the intended V6 branch or copy this branch to a separate V6 repository. Do not change the V5 live branch as part of this draft.
